# atone

Keeps a system's authorization (ATO) true to the system. atone is an **expert pack for
[hobkin](https://github.com/frank-lynam/hobkin)**, and a deterministic toolkit anyone can run without an agent: it
collects evidence from the real system, checks NIST SP 800-53 controls against it, verifies every claim a drafted
narrative cites, fills in the customer's own workbooks, and draws the architecture as it really is (draw.io), with
the drift between the paperwork and the system called out.

Work in progress: see [DESIGN.md](DESIGN.md).
